# QuizBox image prompt bank

Branded subject logos and page images for QuizBox. Written for Gemini or ChatGPT image generation. Revise this file as the brand grows; the logo list itself lives in `docs/brand/subject-logos.json`.

## 1. How to use this bank

1. Open one new chat per batch of 6 subjects, so the style stays consistent inside a batch.
2. Paste the **Master style prompt** first, then one subject line at a time.
3. Ask for **1 image, square, 1024x1024**. Reject any with text, gradients, or more than one emblem.
4. Keep the best, then shrink it (section 4) and save with the exact file name shown.
5. Drop the files into `public/brand/subjects/`. Subjects with no file yet show a coloured letter tile automatically, so you can add logos in any order.

## 2. Master style prompt (paste first, once per chat)

```
Flat vector app icon, single centred emblem on a solid rounded-square tile, 2 to 3 flat colours only plus white, thick even outlines, simple geometric shapes, no gradients, no shadows, no text or letters unless named below, no photo realism, no background scene, generous padding so the emblem fills about 60% of the tile, friendly and clean for school learners aged 6 to 18, consistent with a set of icons that share one style, square 1:1 canvas.
Use this palette family across the whole set: deep navy #0F172A, QuizBox blue #2563EB, warm gold #F5B301, fresh green #16A34A, coral #F43F5E. Pick the tile colour per subject from the colour hint given. Keep the same line weight, corner radius and level of detail in every icon.
```

## 4. Output sizes and file rules

| Use | Size | Format | Folder |
|---|---|---|---|
| Subject logo | 128 x 128 px (shown at 40 px, 2x for sharp screens) | WebP, under 8 KB each | `public/brand/subjects/` |
| Page header banner | 1600 x 400 px | WebP, under 90 KB | `public/brand/pages/` |
| Empty-state illustration | 480 x 360 px | WebP, under 30 KB | `public/brand/empty/` |
| Badge / achievement | 256 x 256 px | WebP, under 15 KB | `public/brand/badges/` |

Shrink with any converter (squoosh.app works in the browser): resize, export WebP at quality 80, check the size. Names are lowercase with hyphens, exactly as listed. Do not rename.

## 6. Acceptance checklist (tick before a file goes in the repo)

- One clear emblem, readable at 40 px.
- No letters or words unless the prompt names them; no misspelt text.
- Same line weight and corner radius as the rest of the set.
- Not a copy of any real brand, school crest or flag.
- People, where shown, are neutral learners in school uniform; no real person's likeness.
- File name and size match section 4.
