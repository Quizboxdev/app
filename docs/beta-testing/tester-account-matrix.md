# Tester account matrix

All accounts live on **Preview** only. Passwords are created by the beta lead and shared through the team password manager; they never appear in this repository. Do not give interns any production, owner or admin credential for the live site.

| Handle | Role | Used for | Notes |
|---|---|---|---|
| qa.student.01, qa.student.02 | Student (adult, not a minor) | STU, CHL, PAY, SEC-01 | Two accounts so one can try to open the other's data |
| qa.student.03 | Student that has used its free sessions | STU-04 | Lead prepares |
| qa.teacher.01, qa.teacher.02 | Teacher | TCH, SEC-03 | Two teachers with one class each |
| qa.child.01 | Teacher-managed young learner | PAY-03 | Created by qa.teacher.01 |
| qa.sponsor.01 | Sponsor | SPN-01 | |
| qa.admin.01 | Admin (Preview only) | ADM | Held by the lead; interns observe or use under supervision |
| (no account) | Visitor | AUTH, SEC-04, UX-02 | |

Email addresses use a mailbox the team controls (for example plus-addressing on a team test mailbox). Reset all accounts at the end of the beta.
